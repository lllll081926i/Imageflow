# 性能基线记录（M0-03 / COMP-07）

> **状态：待实测。** 本文件建立记录格式、测量口径与已固定的输入哈希，并明确区分"本轮已测得"与"尚未测得"。任何数字在没有原始记录之前不得写入结论栏。

## 1. 已固定的测量口径

| 项目 | 口径 |
|---|---|
| 进程内存 | 主进程 + 全部子进程的私有工作集之和；不含系统缓存 |
| 冷启动 | 完全退出所有进程（含托盘、更新检查）后启动，计到首帧可交互 |
| 首屏预览 | 从文件读取到预览画出，含解码、EXIF 归一、缩放、显示 |
| 参数交互 | 连续拖动滑块时的"参数变更 → 新预览可见"延迟 |
| 编码 | 从完整分辨率的源图到输出文件通过校验 |
| 报告统计量 | P50、P95、最大值；重复次数 ≥ 20（首屏 ≥ 30） |
| 记录必填 | commit、Go 版本、OS 版本、CPU/GPU/驱动、输入 SHA256、样本尺寸 |

## 2. 输入样本

基准使用 `docs/Go_Image_Toolbox_Full_Delivery_v2.0/assets/fixtures/` 的合成样本与 `assets/fixture_manifest.json` 的哈希，另外补充仓库内 `internal/codec/testdata/color` 的色彩样本。

| 用途 | 样本 | 说明 |
|---|---|---|
| 中等预览 | `gradient_1280x720.png` | 1280×720，纯渐变，解码与缩放的最优情况 |
| 截图压缩 | `screenshot_text_1600x900.png` | 1600×900，细字体与渐变，文字清晰度的代表样本 |
| 透明与 Alpha | `alpha_512x512.png`、`icon_alpha_256.png` | 半透明边缘，检验预乘约定 |
| 奇数边界 | `odd_1001x667_crop.png` | 1001×667，宫格整数边界用例 |
| 动画 | `animated_basic_6frames.gif` | 6 帧、非均匀时长 |
| 黑白参考 | `bw_400x300_reference.png` | RGB 存储的黑白像素参考；**不是** 1-bit 编码样本 |
| 色彩管理 | `internal/codec/testdata/color/*` | CMYK、HDR10、P3 相关回归样本 |

## 4. 本轮未测得项（不得引用为结论）

| 指标 | 状态 | 缺失原因 |
|---|---|---|
| 冷启动至可交互 | 待实测 | 需要目标设备上的 20 次完全退出重复 |
| 空闲全进程私有工作集 | 待实测 | 需要同时统计子进程；本环境无法采集 |
| 2000×1500 JPEG 首屏预览 P95 | 待实测 | 同上 |
| 参数滑动反馈 P95 | 待实测 | 需要在真实窗口而非渲染测试中计时 |
| 8K 输入与 120 帧 GIF 峰值内存 | 待实测 | 缺少受控内存采集环境 |
| 编码 P50/P95（JPEG/WebP/AVIF/PNG） | 待实测 | 需要固定硬件与重复采样 |
| AI 端到端与显存 | 部分实测 | 已完成双 GPU 小图功能验证，见 `GPU-2026-11-17.md`；P50/P95 与显存峰值尚未测量，分发许可审核未完成 |

## 5. 本轮已取得的间接证据

这些是**自动化回归**的通过记录，不是性能数字：

- `internal/ui` 的逐页渲染测试在固定 1440×900 下渲染 25 个页面，无空白帧、无 panic；该用例同时证明新增页面不会在构建期崩溃。
- `internal/engine` 的色彩、动画、宫格、压缩、标注、像素化用例在本机通过，证明算法路径可达且可重开。
- `internal/capabilities` 与 `internal/png1bit` 的用例证明"声明"与"编码"一致。

## 6. 后续补测要求

1. 在 Win11 x64 目标机上固定电源计划与驱动版本。
2. 每次测量前完全退出所有进程，并确认无 AI 子进程。
3. 用 `assets/fixture_manifest.json` 的哈希校验输入未被替换。
4. 报告必须写出是否包含 ICC 转换、是否包含缩略图缓存命中。
5. 只有"同引擎、同模型、同 GPU"的 AI 对照才可用于任何提速表述。
