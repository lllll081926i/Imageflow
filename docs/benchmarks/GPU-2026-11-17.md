# 真实 GPU 推理验证（2026-11-17）

## 结论与范围

本机真实执行官方 Real-ESRGAN-ncnn-vulkan 引擎及三个模型，未使用辅助进程替身。两个 Vulkan GPU 的直接推理和应用适配器的七条路径全部通过。

这是小图功能冒烟验证，不是性能基准、完整画质评测、显存压力测试或应用窗口人工操作验收。输入来自官方归档的插画示例，不代表自然照片质量验收。没有发布、安装到用户设置或修改默认引擎路径。

## 实测结果

全部使用 Tile=64，每项只运行一次，包含当次模型加载。下表耗时来自适配器 `Report.Elapsed`，仅统计引擎子进程运行，不包含 Go 侧哈希、解码、后缩放和最终提交。不能用于 GPU 性能排名。

| 应用适配器用例 | GPU | 输出 | 引擎耗时 |
| --- | --- | --- | --- |
| realesrgan-x4plus 原生 4× | RTX 4060 | PNG 512×512 | 2.564 秒 |
| realesrgan-x4plus-anime 原生 4× | RTX 4060 | PNG 512×512 | 1.277 秒 |
| realesr-animevideov3 原生 2× | RTX 4060 | PNG 256×256 | 0.951 秒 |
| 照片模型原生 4× 后缩放至 2× | RTX 4060 | JPG 256×256 | 2.297 秒 |
| 照片模型原生 4× 后缩放至 3× | RTX 4060 | WebP 384×384 | 2.294 秒 |
| 视频模型 2×，开启 TTA | RTX 4060 | PNG 256×256 | 0.968 秒 |
| 视频模型 2× | Radeon 780M | PNG 256×256 | 0.436 秒 |

另对两个 GPU 分别执行一次视频模型原生 2× 命令，退出码均为零。完整设备信息、进度和成功输出路径保存在 `engine-gpu-0.log`、`engine-gpu-1.log`。应用适配器对全部结果执行格式、尺寸与解码校验，再原子提交。测试再次解码并核对报告尺寸。

`comparison.png` 左侧为 128×128 输入，右侧为照片模型的 512×512 输出。已查看对比图：输出非空，内容方向与输入一致，未见整图黑屏或明显拼块缺失。不据此声称超分辨率恢复了真实细节。

## 发布前追加验证（Go 1.27.4）

真实 RTX 4060 执行 `gpu_release_test.go`，证据位于 `build/release-acceptance-20261117/gpu/` 与 `gpu-test.log`。

| 输入 | 输出 | 引擎耗时 |
|---|---|---|
| 截图 1600×900 | 6400×3600 | 9.697 秒 |
| 奇数尺寸 1001×667 | 4004×2668 | 2.836 秒 |
| 半透明 512×512 | 1024×1024 | 1.299 秒 |
| 透明图标 256×256 | 1024×1024 | 1.729 秒 |
| 自然照片 TIFF 600×400 | 2400×1600 | 5.909 秒 |
| EXIF 方向 6 | 100×140，方向正确 | 3.271 秒 |

活动 4× + TTA 推理在 2 秒后取消，约 0.499 秒返回取消错误；既有目标完整且临时文件清理。双 GPU 小图测试最终复跑也通过，见 `gpu-smoke.log`。

实测暴露并修复透明输入输出全透明的问题：适配器先解码、校正方向和色彩，生成白底 PNG 输入引擎，再对 PNG/WebP 恢复缩放后的 Alpha。已查看透明图及自然照片输出；不承诺模型恢复真实细节，也不把单次耗时当性能基准。
