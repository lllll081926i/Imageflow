# 应用体验逐项审计与优化记录

## 使用规则

- 本文作为体验优化的唯一进度台账；开始修改前先检查对应问题编号。
- 按实际任务审计，不以控件存在或页面能打开作为验收完成。
- 每项记录包含问题、改动、验证和剩余限制。没有验证的项目不标记为完成。
- 已完成项目只做回归；发现新问题时新增编号，不重复重做设计。
- 不增加教学性长文案。说明优先放在必要的字段、状态与提示中。
- 本轮只做本地开发和验收，不执行版本发布。

## 共用验收标准

1. 导入、选图、调整参数、执行、取消、定位结果形成完整操作链。
2. 空状态、处理中、失败、完成状态清楚，不显示误导性预览。
3. 控件真实修改参数；跨分组选择、零值、边界值可用。
4. 预览与导出使用相同参数；需要预览的页面完整适配图片。
5. 960 × 620 与 1440 × 900 下无越界；长图、宽图与大量文件可操作。
6. 图片、模型、导出文件与临时缓存按既有安全约定隔离。

## 问题与实施记录

### UX-001：AI 预览操作区过重

- 问题：顶部模式、重置与缩放控件重复占用画布空间。
- 实施：移除顶部选项，保留左原图／右结果拖线；滚轮缩放、右键／中键平移、双击复位。
- 验证：拖动过程及端点像素检查、真实鼠标滚轮、双击复位、源区域边界检查通过。
- 定位：`internal/ui/upscale_preview.go`、`internal/ui/upscale_interaction_test.go`。

### UX-002：文件队列效率与左右边距

- 问题：列表右侧内边距为 0；只能逐行查看大量图片。
- 实施：统一左右 16 DIP；增加列表、网格、紧凑排列；虚拟化可见行；键盘 Home／End 与选中项跳转。
- 验证：80 张队列的三种排列、选择、移除、键盘跳转通过；全部工具双尺寸布局回归通过。
- 定位：`internal/ui/app.go`、`internal/ui/files.go`、`internal/ui/efficiency_test.go`。

### UX-003：预览超框与长宽图裁断

- 问题：自然图片高度撑开容器；仅裁剪容器无法保证完整显示。
- 实施：明确预览可用高度；图像在限定空间等比适配；标注和拼图不再由图片固有比例撑开外框。
- 验证：40 × 800、800 × 40、小窗口和双尺寸全工具边界检查；小预览上下分区像素检查。
- 定位：`internal/ui/app.go`、`internal/ui/collage.go`、`internal/ui/tools_studio.go`。

### UX-004：所有页面机械使用大预览

- 问题：批处理页与分析页的大原图挤占文件操作区。
- 实施：PDF、GIF、分析取消静态原图；转换、尺寸、压缩、图标、宫格、行列切分、长图拼接、取色使用小预览；编辑与对比保留主画布。
- 验证：各类页面的预览有无、预览高度、文件列表空间检查。
- 定位：`toolPreviewMode`、`TestPreviewSpaceMatchesToolTask`。

### UX-005：裁剪比例分组选择

- 审计发现：比例分成两行，但第二行只在已经选中第二组时回写，第一组无法切入第二组。
- 实施：比例改为共享索引的三列按钮；跨组与自定义可直接选择。提取 `engine.RenderCropImage`，预览与导出共用裁剪、取景、缩放、圆角逻辑；预览长边限制为 2048，真实导出尺寸不受该限制。
- 验证：真实点击第二组、第一组、自定义再切回通过；64 × 40 圆角裁剪的预览与 PNG 导出逐像素一致。
- 定位：`internal/ui/tools_extra.go`、`internal/engine/cropbox.go`、`TestAuditCropRatioCrossGroupSelection`、`TestAuditCropAndWatermarkPreviewMatchExport`。

### UX-006：基础编辑翻转控件横向争抢空间

- 审计发现：两个占满宽度的开关放在同一行，窄窗口下需要检查文字和点击区域。
- 实施：两个开关改为等宽两列，保留现有功能和默认值。
- 验证：双尺寸全页边界回归、基础编辑端到端回归。

### UX-007：富文本编辑被每帧默认值覆盖

- 问题：配色每帧重套主题；清空标题、正文后默认文本又回来；非浅色主题在引擎端再次覆盖自定义颜色。
- 实施：默认值只初始化一次；仅切换主题时应用配色；UI 向引擎提交最终颜色，不重复提交覆盖颜色的主题键。移除默认正文中的技术栈介绍。
- 验证：连续四帧保留空文本和自定义颜色；深色主题改红色背景后，实际导出 PNG 保留指定 RGB 值。
- 定位：`internal/ui/tools.go`、`TestAuditRichTextEditsSurviveFramesAndExport`。

### UX-008：画布留白区误绘制与反向拖动失真

- 问题：预览完整适配后，留白仍可创建标注；反向拖动被当成单击并重设尺寸。
- 实施：仅左键在图片实际区域开始绘制；拖动终点限制在图片内；使用位移绝对值判断单击；默认尺寸不越界。
- 验证：标注／拼图留白点击不产生标记；图片内仍可绘制；反向拖动保留方向。修正旧拼图测试，按真实图片矩形而不是整个留白画布选取坐标。
- 定位：`internal/ui/tools_studio.go`、`internal/ui/collage.go`、`TestAuditAnnotationIgnoresLetterbox`、`TestAuditCollageIgnoresLetterbox`。

### UX-009：无效质量控件与尺寸标签挤压

- 问题：PNG 编码不使用质量参数，但多个页面仍显示质量；多个目标尺寸标签挤在一行。
- 实施：按目标编码器和原格式队列判断质量控件是否适用，覆盖尺寸、宫格、切分、拼接、水印和压缩；水印不生成空的输出分组。尺寸预设标签自动换行。
- 验证：六页 PNG 输入／输出不显示质量；JPG 能力仍启用质量；现有多尺寸导出回归。
- 定位：`qualityRelevant`、`TestAuditQualityControlsFollowEncoder`。

### UX-010：拼接尺寸名称误导与无效边框字段

- 问题：“目标长边”实际控制竖向拼接的统一宽度或横向拼接的统一高度；关闭边框仍显示边框宽度。
- 实施：按方向显示“统一宽度／统一高度”；仅启用边框时显示边框宽度。
- 验证：拼接端到端导出与顶部／底部参数截图回归。

### UX-011：纯文本制图反而要求导入图片

- 问题：没有输入图片时不能开始；预览只有导出后才生成；配图路径抢占按钮空间。
- 实施：提供无源图实时画布和独立 PNG 导出；无源图时必须先指定输出目录，禁止写入不明确的当前目录；沿用命名与冲突策略；保留有输入时的批处理。纯文本画布不显示空文件队列，配图路径使用剩余宽度。
- 验证：空队列生成 800 像素预览并导出一个 PNG，队列不受污染；未指定输出位置时停止；有输入端到端导出通过。
- 定位：`RichTextTool.request/Run`、`toolRunsWithoutList`、`TestAuditRichTextRunsWithoutInput`、`TestAuditRichTextNeedsExplicitOutputWithoutInput`。

### UX-012：设置保存位置随环境变量漂移

- 问题：每次后台保存重新读取设置路径，旧会话的延迟写入可能覆盖新会话的文件；与此前全量测试偶发保存失败的条件吻合。
- 实施：创建 Session 时固定设置路径；新增 `settings.SaveTo`，保留原 `Save` 调用方式。设置内容仍由会话事务锁与原子替换保护。
- 验证：两个会话切换环境路径后分别写入，只改变各自的文件；设置滚动保存和代理设置回归通过。最终全量结果另记，不仅凭定向通过结案。
- 定位：`internal/batch/session.go`、`internal/settings/settings.go`、`TestSettingsWritesStayWithTheirSession`。

### UX-013：多选项预设过密

- 问题：调色八个预设同排；像素画五个尺寸预设及英文抖动算法被挤压。
- 实施：调色四列、像素尺寸三列、抖动算法两列；使用同一稳定索引按钮组件，不引入跨组状态。
- 验证：25 页带图顶部／底部截图；像素与调色预览、导出回归。

### UX-014：分析固定首张且快速换图丢请求

- 问题：只能“分析首张”；分析期间再次选图被忽略；任务刚启动就提示已分析。
- 实施：改为“分析选中”；记录最后请求并在旧任务返回后分析最新图片；过期结果不覆盖新选择；实际完成后才显示完成状态。
- 验证：连续提交两张不同图片，最终结果与状态对应第二张。
- 定位：`AnalysisTool.Panel/analyse/Run`、`TestAuditAnalysisKeepsLatestSelection`。

### UX-015：顺序型任务不能直接重排队列

- 问题：拼图、长图拼接和 PDF 等依赖文件顺序，原队列必须移除再导入。
- 实施：列表、网格、紧凑三种排列均支持拖动重排；按文件路径保持身份及结果状态；导入和处理期间禁止重排；拒绝缺项、重复路径和过期队列。
- 验证：三种排列真实拖动后顺序更新；处理中重排被拒绝；会话级非法顺序保护和身份回归。
- 定位：`Session.ReorderFiles`、`App.reorderInputs`、`TestAuditReorderInputsByDragging`。

### UX-016：调整参数时预览闪回原图

- 问题：每次参数变化先清空上一张效果图，短暂显示原图。
- 实施：同一来源、同一工具计算新效果时保留上一张完成的预览，并显示“更新中…”；切换来源不保留旧图。
- 验证：旋转参数改变时预览保持上一帧，计算后更新；现有换图和不叠加变换回归。
- 定位：`requestStudioPreview`、`TestAuditStudioKeepsLastPreviewWhileUpdating`。

### UX-017：图片对比参数与报告不一致

- 问题：修改对齐方式或差异放大后没有重新计算；计算中仍可导出旧指标；有效的 0 dB 显示为“—”；内部枚举直接显示在页面和报告。
- 实施：参数变化启动重算；计算中拒绝导出旧指标；0 dB 作为有效测量值；页面与报告统一中文对齐方式。
- 验证：0 dB 边界测试；对比计算和报告冲突保护回归；参数更新与忙碌导出保护回归。
- 定位：`CompareTool.Panel/Run`、`psnrText`、`compareAlignLabel`。

### UX-018：首页组件状态不准确

- 问题：首页尚未探测组件就显示未就绪，并展示技术性登记模型数量。
- 实施：首页未探测时明确显示“尚未检查”，移除登记数量并提供打开入口；修正压缩和 AI 工具简介，描述实际可用功能。
- 验证：首页导航与搜索回归。
- 定位：`homeComponentState`、`toolSummary`。

### UX-019：PDF 密码明文显示

- 问题：打开密码使用普通输入框，旁人可直接看到内容。
- 实施：使用密码输入掩码，保留原来的加密参数。
- 验证：Password 属性检查与引擎加密导出回归。
- 定位：`PDFTool.Panel`、`TestAuditPDFPasswordIsMasked`。

### UX-020：取景方向排成横条

- 问题：九个位置横向排列，用户必须先读箭头再推算图片位置；水印使用普通 Row 接受点击，缺少标准按钮的键盘行为。
- 实施：裁剪、基础编辑、水印共用三行三列方向按钮；中文无障碍名称与悬停提示；使用 ButtonBase 保留键盘和焦点行为。
- 验证：三页逐个点击九个方向，确认写入对应位置；左上与右下的实际几何位置符合九宫格。
- 定位：`anchorPicker`、`TestAuditAnchorPickerMatchesImageDirections`。

## 第二轮：操作链优化（2026-11-17）

本轮接续 UX-020，不重做首轮页面布局。重点是文件队列、处理保护和结果定位；六项定向控件回归、最终全量、竞态、静态检查与开发版构建均通过。结果入口只覆盖有成功队列输出的操作，无输入画布的结果入口留待后续扩展。

### UX-021：处理期间仍能清空队列

- 问题：处理中可点击清空，导致正在处理的行和后续结果失去展示位置；输出位置按钮也仍可点击。
- 实施：处理中禁用清空和选择输出位置；清空动作自身检查运行状态。空闲清空继续取消导入，使尚未提交的导入结果失效，不删除源文件。
- 验证：真实点击禁用按钮与直接调用均保留运行队列；空闲点击清空同步清除队列与预览。
- 定位：`App.clearInputs`、`TestWorkflowClearProtectsActiveRun`。

### UX-022：连续移除图片必须反复寻找关闭按钮

- 实施：列表、网格、紧凑排列均支持 Delete 移除选中项，沿用移除后的相邻选图规则；处理中和导入中不执行。命令仅绑定图片列表，不占用参数输入框的 Delete。
- 验证：三种排列真实键盘操作及处理中保护通过；参数输入框不会触发移除。
- 定位：`App.fileBrowserGrid`、`TestWorkflowDeleteSelectedInput`、`TestWorkflowDeleteDoesNotStealParameterInput`。

### UX-023：空闲取消无效，完成后缺少直接查看结果入口
