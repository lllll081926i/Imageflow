## 模型可信清单

AI 页新增可信模型清单导入。导入在后台执行；程序验证字段、文件配对、哈希和倍率。校验成功后原子保存至模型根目录的 `imageflow-models.json`。后续探测和推理会重新读取该清单，不修改全局默认注册表，也不自动信任本地计算出的哈希。

清单是 JSON 数组，每项使用以下字段：

| 字段 | 约束 |
| --- | --- |
| `name` | 模型子目录名称，不得包含路径 |
| `param_file` / `bin_file` | 同名前缀的 `.param` / `.bin` 文件名，不得包含路径 |
| `sha256` | 64 位十六进制；按参数文件、权重文件的顺序拼接原始内容后计算 SHA256 |
| `scale` | 模型原生倍率，2–4 |
| `purpose` / `license` | 真实用途和许可证说明，不能为空 |

**先核对权重来源，再导入清单。** 拼接哈希不是两个单文件哈希字符串的拼接。清单只提供完整性基准，不代替来源审核、数字签名或许可证审核。不得把未知来源的权重和同源未知清单视为可信组件。

文件布局为：模型根目录 / `name` / 模型文件。默认动漫视频模型使用 `realesr-animevideov3/realesr-animevideov3-x2.param` 和配对 `.bin`，传给引擎的模型标识仍为 `realesr-animevideov3`。

新增双源下载后，已通过官方 HTTPS 下载实际核验归档及三个模型哈希，并实际验证 GitHub 和国内加速两种来源。没有捏造许可证批准记录。真实引擎、GPU、权重画质与许可证分发仍需要独立验收。

## 实现边界

- 共享预览从保留的源图渲染，不从上次处理结果继续渲染。预览与导出共用请求构造和引擎函数。
- 预览按工具、源图版本和参数快照建立任务键。替换请求会取消旧 context，并拒绝旧结果。单个任务队列串行渲染，避免同时分配多个大画布。
- 没有 context 接口的内存渲染函数可能完成当前计算后才停止；取消保证旧结果不再发布，不声称能在任意像素位置抢占计算。
- 动画编码在帧准备和输出写入阶段检查取消。底层原生编码调用仍可能在返回后才能观察取消；已取消的输出不提交。
- AI 调度回归使用测试可执行文件作为辅助进程，验证参数、失败、损坏输出和取消，不代替真实模型测试。
- 路线图中的目标体积、接缝优化、水印变量、GIF 时间轴、真实 GPU 性能与六平台原生安装验收仍保留原状态。
