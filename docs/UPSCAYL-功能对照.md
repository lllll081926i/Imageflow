# Upscayl 功能对照与验收

## 基准与边界

- 对齐 Upscayl v2.15.0，提交 `4f39acfc6f88260d105920a64deff8431d5e1544`。
- 以公开参数和操作行为独立实现 Go 宿主，不复制 Electron/React 源码。
- Upscayl 与 upscayl-ncnn 使用 AGPL-3.0。外部组件按固定提交下载，不混同 ImageFlow 的 MIT 许可。模型许可必须单独核对，不能将宿主许可当作模型授权。
- 不再提供旧 Real-ESRGAN 模型。正常启动时将旧版三个模型的已知文件、旧引擎和对应登记记录移出工作目录，放入 `models/.trash/legacy-*`。保留自定义模型和未知文件；迁移失败保留原文件并记录错误，下一次启动重试。
- 下载、暂存、引擎、模型保存在程序的 `models/`，使用设置中的下载源和代理。

## 功能清单

| 功能 | 实施要求 | 验收要求 |
| --- | --- | --- |
| 七个官方模型 | Standard、Lite、High Fidelity、Remacri、Ultramix、Ultrasharp、Digital Art；High Fidelity 资源名为 hfa2k-4x | 固定提交、逐文件摘要、真实 GPU 输出 |
| 单图、文件夹、批量 | 复用输入队列、目录递归、取消与冲突策略 | 单图和批量均不覆盖输入，取消保留原文件 |
| 倍率 | 1–16×，区分原生推理和最终缩放 | 严格检查中间图和目标图像素预算 |
| 自定义宽度 | 保持比例，替代最终倍率 | 输出尺寸准确，超限提前拒绝 |
| 双重放大 | 执行两次推理，不用一次插值冒充 | 两次 GPU 调用，中间文件清理、输出原子提交 |
| GPU、Tile、TTA | 显式参数与可取消进程 | 自动/指定 GPU，显存错误可诊断 |
| PNG/JPEG/WebP、压缩 | 格式与质量参数 | 实际解码格式、尺寸、透明通道校验 |
| 自定义模型 | 导入 NCNN 文件对到固定模型目录 | 文件配对、倍率、路径和大小检查，明确本地来源，不能冒称官方可信 |
| 滑动对比、鼠标缩放 | 原图与实际结果同步，滚轮缩放、右键平移、双击复位；按新版交互要求移除放大镜与顶部选项 | 鼠标、键盘、切图后结果不串图 |
| 进度、日志、结果 | 单图进度、批量进度、耗时、结果入口 | 工作线程不写视图状态，取消后不回写过期结果 |
| 参数记忆、重置 | 仅在 AI 页面配置参数 | 重启恢复，重置不破坏下载的模型 |
| 粘贴图片、拖放 | 使用现有系统输入能力 | 真实系统剪贴板验收 |
| 操作统计 | 本地统计，单图/批量/双重与耗时 | 不上传图片、路径或遥测 |
| 应用设置、更新、通知 | 复用 ImageFlow 现有能力 | 不复制品牌页面、捐赠链接和云服务账户 |

## 实施顺序

1. 固定资源与摘要，建立后端适配和安全下载。
2. 实现推理参数、两次推理、尺寸和输出校验。
3. 完善模型管理、参数记忆和结果交互。
4. 优化共享预览与文件排布，补充真实交互测试。
5. 运行全量测试、静态检查、真实 GPU 和打包验收。

## 本轮实施与核验（2026-11-17）

功能清单中的本地功能已实现。完成通知使用系统通知接口，是否展示由系统通知权限与免打扰策略决定；云服务账户、捐赠、遥测和上游品牌页面不集成。

- 七模型真实 GPU 输出通过；RTX 4060、Radeon 780M、自动选择及 `0,1` 参数通过。单张图片不承诺同时利用两块 GPU 加速。
- 两次推理、自定义宽度、JPEG/WebP 压缩、TTA、透明与半透明图通过；大图 1600×900 → 6400×3600、奇数尺寸 1001×667 → 4004×2668 通过。
- 活动 GPU 推理取消约 0.54 秒，既有目标内容保持不变。宿主额外拒绝输入与输出为同一文件。
- 对比分隔线通过鼠标按下、移动、松开和像素检查；拖动期间实时更新，覆盖左右端点和双击复位。滚轮缩放、右键平移、参数记忆、高级区反复折叠和 PNG 剪贴板导入通过。
- 临时粘贴原图在应用实际退出时清理；异常退出遗留超过 24 小时后清理。设置页提供分类容量和一键清理，保留当前会话原图、模型、源文件、导出结果及未知文件。

证据：`build/upscayl-final-acceptance/gpu.log`、`tests.log`、`race.log`、`package.log`；交互回归位于 `internal/ui/upscale_interaction_test.go` 与 `internal/ui/cache_test.go`；缓存白名单、过期和会话隔离回归位于 `internal/appcache/cache_test.go`。

当前只完成 Windows x64 的原生与真实 GPU 验收；其他平台下载资源已固定，但未完成原生推理验收。没有执行极限显存或长时间画质评测。本轮只构建本地开发版及本地验收安装包，不打标签、不签更新、不发布。
