# ImageFlow Go — 界面样式契约

本文件是 Go 重写版（`imageflow-go/`）的视觉契约，逐条对齐原项目
[docs/DESIGN.md](../../docs/DESIGN.md)。改任何颜色、圆角、间距或动效前先改这里，
再改 `internal/ui/style.go`。

实现位置：`internal/ui/style.go`（tokens 与主题注入）、`internal/ui/controls.go`
（组件模式）、`internal/ui/app.go`（外壳布局）。

---

## 1. 设计原则

1. **内容优先**：控件退后，图片与结果前置。
2. **单一强调色**：全应用只有一个品牌蓝，语义色仅用于状态反馈。
3. **物理感动效**：可交互元素有按压回弹，切换有颜色过渡。
4. **明暗双主题对等**：每个 token 都有 light / dark 两套值。
5. **尊重系统设置**：MyGo 的 `Theme.Preferences` 与 `prefers-reduced-motion` 由框架接管。

Lobe MyGo 默认把 `Accent` 设成近黑色。`applyBrandTheme` 在每一帧把 frame 的
`Accent / Focus / Background / Text / Border / Surface` 重新指向本文件的 token，
所以滑块、开关、输入框焦点环都用品牌蓝，而不是灰黑。

窗口最小 `960 × 620`，默认 `1440 × 900`。

```
│          │ ┌─────────────────────┐ │ 输出格式 / 尺寸 / 高级   │
│ 工具箱    │ │ 输入项 4 · 转PDF 按钮 │ │                         │

│ · 尺寸调整│ │ 预览区（有图时出现）   │ │ 滑块行                  │
│ …        │ ├─────────────────────┤ │ 开关行                  │
│          │ │ 虚线拖放区 + 文件行   │ │                         │
│          │ └─────────────────────┘ ├─────────────────────────┤

└──────────┴─────────────────────────┴─────────────────────────┘
```

| 元素 | 尺寸 | 断言位置 |
| --- | --- | --- |
| 标题栏 | 高 48 | `TestShellGeometryAtDefaultSize` |
| 工具卡 | 宽 216（收起后 72） | 同上 + `TestRailCollapses` |
| 参数卡 | 宽 420 | 同上 |
| 输入卡 | 其余宽度，至少 100 | 同上（含 960×620 最小尺寸） |

## 5. 组件模式

### 5.1 分段控件（SegmentedControl）

```
轨道：Recessed 底，圆角 12，内边距 3
药丸：Card 底 + Divider 1px 描边，圆角 8，高 30
选中：Text 600 字重；未选中：TextSub 500
```

**不要**用白色实心药丸：在深色模式下会变成白底白字（本轮踩过）。

### 5.2 参数卡片（sectionCard）

```
Card 底 · 圆角 16 · 1px Divider 描边 · 内边距 16 · 组间距 12
标题：12px / 600 / Text
```

### 5.3 滑块行（sliderRow）

```
标签 12px/500/TextSub      数值 11px/600/Text 装在 Recessed 小胶囊里
滑轨：连续滑块（不用带刻度版本，那是"尺子"观感）
```

### 5.4 主操作（开始处理）

```
高 46 · 圆角 12 · Gradient(Brand, BrandGradientTo, 90)
白色 14px/600 文本 + Play 图标 · BrandGlow 阴影（0,6,16）
进度条：高 5 · 全圆 · Recessed 轨道 + 品牌渐变填充
运行中：Recessed 底 + TextDim 文本 + X 图标，点击即取消
取消：ghostButton（描边胶囊），仅在空闲时出现
```

### 5.5 导航项

| 状态 | 样式 |
| --- | --- |
| 选中 | 渐变填充 + 白字 600 + BrandGlow 阴影 + 图标底座 `rgba(255,255,255,.22)` |
| 悬浮 | `Recessed` 底 |
| 常态 | 透明 + 32×32 图标底座 `featureTintPlate`（浅色 15% / 深色 25% 色相）+ 图标 `featureTint` |

行高 48、左右内边距 8、图标底座与文字间距 11。图标底座是本系统与普通文字菜单的区别：
去掉后侧栏会变成一列纯文本。

### 5.6 拖放区

空列表：`Recessed` 底 + 虚线 `Divider` 描边 + 居中圆形 `BrandSoft` 图标底。
有文件：**改实线描边**——虚线围着可滚动列表会读成「还没填的占位」。
拖入中：`BrandSoft` 底 + 实线 `Brand` 描边。

文件行：高 62、内边距 7/9、缩略图 48、名称 + 格式徒标、第二行「尺寸 · 大小」、
右侧固定 84 DIP 状态列，悬浮时整行 `Recessed`。

### 5.7 参数分组标题

`sectionCard` 的标题前有一条 3×11 的品牌色竖条，与标题同基线。
没有这条竖条时，一组组控件会读成一整张长表单。

### 5.8 控件状态与反馈

- 按钮使用可键盘聚焦的 `ButtonBase`：常态描边 / 品牌渐变，悬浮提高边界或渐变亮度，
  按压轻微缩放，禁用使用 `Recessed + TextDim` 且不再响应点击，加载用旋转指示与文字双编码。
- 输入框、数字框、多行框与选择器统一 38 DIP 高、10 DIP 圆角：常态 `Recessed + Divider`，
  悬浮提高描边对比，聚焦用品牌描边与 2 DIP 柔光环，错误用 `Danger` 描边 / 柔光环，
  禁用只读灰化并显示禁止指针。颜色与文字同时表达状态，不只依赖颜色。
- 开关、分段与滑块保留 Lobe 的紧凑尺寸和中性填充，只强化悬浮、按压、键盘焦点；
  不用大面积品牌色制造额外噪声。
- 设置页宽屏（窗口 ≥1200 DIP）为左右独立双列，窄屏为单列；命名、位置、行为、更新、关于
  保持独立分组，底部保存栏固定。窄窗口缩小页边距，保存栏换成两行，避免按钮挤压状态文字。
- 添加文件、批处理完成 / 失败、保存输出目录等 `App.Status` 在操作栏中有可见出口；
  成功、警告、失败由图标、文字和语义色共同表达。

### 5.9 侧栏拖动排序

工具行支持长按拖动重排，三层效果共同构成一次可读的手势：

| 阶段 | 表现 | 曲线 |
| --- | --- | --- |
| 按住 380 ms | 行抬起：`Scale(1.04)` + `Shadow(0,8,20,.22)`，`ZIndex(3)` 置顶 | 即时 |
| 拖动中 | 被抱行跟随指针 | `EaseOut` 110 ms（弹簧跟随移动目标会振荡） |
| 让位 | 原位置与目标位置之间的行各平移一格 | 弹簧 300 ms / `Bounce .22` |
| 释放 | 过半个行高即吸附到相邻槽位，其余行弹簧归位 | 同上 |

顺序存储为「位置 → 工具索引」的排列，因此当前页面、选中指示与工具身份都不随搬动而变。
行位移用 `Translate`，不用 `Top`：行仍在流式布局里，这样图标底座始终在同一条轴线上；
`Top` 只对 `Absolute` 元素生效，误用会把后续行整列往下推。
指针位移取 `Dragged()` 的窗口轴增量：行自己在移动，用行内局部坐标算位移会自抵消。

### 5.10 工具自绘预览

工具的预览默认是输入卡里的「单张图片 + 尺寸」。拼图不是这个形状：它把多张输入
合成一张，并且要接受指针操作。`Tool` 之外的 `previewWidget` 接口让这类页面
自己画预览区：

- `App.inputCard` 发现当前工具实现了 `PreviewPanel` 时，把预览区交给工具，
  文件列表改为固定 168 DIP 高的紧凑拖放区（保留添加入口与右键移除）。
- 预览画布是 `Box` + `Clip`，不在内部铺卡片底色以外的层：拼图位图自己带背景。
- 指针输入走 `HandleInput`：按下选中格子，`Button == 0` 的移动平移取景，
  `Ctrl + 滚轮` 调缩放，方向键微调，双击提示换图。
- 屏幕 DIP 到画布像素的换算必须与导出共用 `collage.Layout`：否则点中的格子与
  画出来的格子会错位。
- 预览合成走后台 goroutine，结果经 `Window.Update` 回到界面线程；旧的合成结果
  以代数计数丢弃。新请求取消旧任务，同一工具的预览串行合成，避免积压大画布。
  没有窗口（测试 / 命令行）时就地合成，避免跨线程写字段。
- 复制操作在后台合成并编码 PNG，仅在界面线程写入剪贴板。恢复默认设置与真正关闭窗口
  会取消预览和复制任务，并拒绝已经排入窗口队列的旧结果。
- 导出启动时快照全部分组请求，后台不再读取或写入拼图工具字段。每组独立提交成功、
  失败、跳过或取消结果；取消不覆盖已经提交的输出。
- 输入行具有会话内唯一身份和运行代数。任务结果按两者提交，不按可变的列表索引回填。
- APNG 路径在冲突检查前统一使用 `.apng` 后缀。图标集以整个目录执行冲突策略。
  APNG 帧延迟先约分，无法用 16 位分子精确表示时返回错误，不回绕或覆盖旧文件。
- 预览的长边固定 1024，因此以画布像素表达的长度（边距、间距、圆角）按比例缩小，
  否则预览看起来比导出更紧。

## 6. 动效

| 用途 | 值 |
| --- | --- |
| 按压回弹 | 即时 `Scale(0.99)` + `Snappy` 弹簧 `180ms` / `Bounce .08` 的阴影淡变（`springTap`） |
| 卡片内换内容 | `EaseOut` 曲线 `200ms`，`Y: 4 → 0` + 淡入（`springSoft`） |
| 切页 | 共享 `shellCurve`：`EaseInOut` `220ms`，仅不透明度 `0.72 → 1`（`pageSwap`） |
| 分段控件滑块 | `EaseOut` 曲线 `180ms`（`segmentSlide`） |
| 侧栏收起 / 展开 | 共享 `shellCurve`：`EaseInOut` `220ms` 宽度动画 216 ↔ 72 |
| 选中指示、标签、底部高亮 | 与宽度同帧渐变，或共享 `shellCurve` 淡入淡出；不另设曲线 |
| 加载指示 | `Linear` 曲线 `900ms` 循环；减弱动效时静止，以文字表达加载状态 |

**MyGo 语义陷阱（必须记住）**：`ElementTransition` 若一个属性标志都不设，
框架按「全部属性」处理 —— 位置、尺寸、颜色、阴影都会动画，而不是「不做过渡」。
本系统的所有预设都显式设 `Shadows: true`，含义是「布局盒不参与过渡」：
父 `Row` 每帧把动画后的侧栏宽度喂给布局，子元素必须用同一帧的新几何，
不能用自己的曲线再缓动一次。否则中间卡片会在收起途中落后侧栏 150 DIP 以上。
`Enter` / `Exit` 由 `Motion` 驱动，与属性标志无关，所以淡入淡出照常生效。

不给颜色加过渡：`Colors: true` 会从零色开始插值，深色主题首帧会闪白。

减弱动效必须返回 `ElementTransition{Duration: -1}`，而不是零值过渡：
零值等价于「全部属性 + 默认 200ms 动画」，反而更慢。负时长是 MyGo 文档定义的
「所有变化、Enter、Exit 立即到位」。

切页只做 `Enter`，不做 `Exit`：两页装着同一套卡片，退出副本会在原页面上再画
一份标题与标签，半途的重影反而像卡顿。淡入起点是 `0.72` 而非 `0`：从全透明起步
会让整个内容区先空几帧，读起来像窗口刷新了一遍。

侧栏行的身份必须稳定：选中指示常驻（设置页只淡出，不移除子元素），每个工具行、
底部项都带固定 `Key`。MyGo 未加 Key 的子元素按「父 ID + 子序号」识别身份，
移除列表第一个子元素会把后面 13 行全部重编号，整列被当成新元素重建。

## 7. 无障碍

- 每个可点击元素都给 `Label(...)`，作为可访问名与悬浮提示来源。
- 状态用「颜色 + 文字」双编码：文件行用状态胶囊，文字写「已完成 / 失败 / 已跳过」。
- 文本对比度：`TextSub` 在 `Card` 上为 7:1 以上，`TextDim` 仅用于辅助说明。

## 9. v3.2.0 增量（对照 v2.0 交付包）

本节的样式决定沿用上面的 token 与组件模式，不新增第七种控件外观。

### 9.1 新增页面的参数栏结构

新页面统一采用「分组卡片 + 单列控件」的参数栏，顺序固定为：**内容/数据 → 样式 → 位置 → 输出**。
原因：这十一个页面的参数数量都超过一屏，分组顺序一致后，用户在不同页面之间不需要重新建立心
智地图；「输出」永远在最下方，与底部动作栏相邻。

### 9.2 新页面沿用的既有组件

| 组件 | 复用位置 |
| --- | --- |
| `sectionCard` | 全部新页面的分组容器 |
| `segmented` / `segmentedSwitch` | 调色预设、滤镜库、抖动算法、对齐方式、输出格式 |
| `sliderRow` | 曝光、对比、强度、半径、不透明度、圆角 |
| `colorField` | 填充色、描边色、背景色、黑白两色 |
| `numberField` | 画布尺寸、图层 X/Y/W/H、目标分辨率、Tile |
| `switchField` | 锁定、显示、投影、反相、1-bit 编码 |
| `statusPill` | 组件状态（引擎可用 / 组件缺失 / 不可逆） |
| `warnAlert` | 8 位调色声明、安全遮盖提示、1-bit 非 PNG 提示 |
| `metricRow` | 对比指标、图像统计、模型状态 |
| `histogramBars` | 图像分析的直方图（每帧只画 64 根柱，不做 256 个元素） |

### 9.3 三条新增的视觉约束

1. **工具色板必须与工具数量等长。** `featureTint` 现在有 25 个条目，一页一条；两页共用一色会
   让侧栏读成无序菜单（`TestEveryToolHasItsOwnTint` 固定）。
2. **画布型页面自己拥有预览。** 自由布局、标注、对比三个页面实现 `previewWidget`，输入卡只
   提供紧凑文件列表；其余新页面沿用共享的单图预览。
3. **不可逆操作必须与美观操作在颜色之外区分。** 安全遮盖在标注列表里带「不可逆」胶囊，并且
   `IsIrreversible` 决定它用 `Text` 而不是 `Danger` 着色：颜色不是唯一编码。

三条约束：

1. **卡片一律用列布局。** 行布局的 `AlignItems(Center)` 在卡片高于内容时会把图标和标题拉到垂直居中，
   描述再换行就变成被截断的一团；列布局让头部保持顶部对齐。
2. **折叠态不留文字。** 72 DIP 放不下输入框与分组名，挤压后的控件既不可用也不可读；
   因此搜索转为图标按钮、分组标题转为分隔线、工具行只留图标底座。
3. **选中指示的位置取自行表。** 分组标题高 28 DIP、行高 48 DIP、间距 2 DIP，三者叠加后不存在「行距」这个常量；
   指示与拖拽都读同一张 `railRows()` 表。

### 9.7 新增工具的任务与预览契约

1. 标注输入只保存稳定 `ui.Handle`，不在后续输入回调使用旧 `ui.Element`。
2. 参数控件归 UI 线程所有。运行和预览先构造参数快照，再交给后台任务。
3. 共享预览始终从源图渲染。工具、源图版本、参数共同标识任务；旧任务不得发布覆盖新任务。
4. 文件解码、模型哈希、外部引擎探测与 LUT 读取不得在视图构建中同步执行。
5. AI 与表情批处理使用批次 context。关闭实际退出窗口时取消批次和新增后台任务。
6. AI 正式目标只在格式、尺寸、解码和资源预算校验后原子提交。模型可信记录由固定哈希校验后的下载器持久保存，禁止自动信任未经校验的权重。

详细修复和模型清单格式见 `docs/REPAIR-2026-11-17-INDEPENDENT.md`。

### 9.8 AI 模型下载契约

1. 设置页仅提供默认源、HTTPS 加速前缀、代理模式与代理地址；不再提供引擎和模型路径选择。
2. 默认源为官方 GitHub。Upscayl 资源固定到 v2.15.0 提交；国内加速提供同一资源的第三方转发地址，两种源均遵循所选代理模式。
3. 默认代理模式为 system，依次读取环境代理、Windows 静态代理、备用地址 `http://127.0.0.1:7890`。不解析 PAC 或非 Windows 原生代理配置。连接失败不得静默直连。
4. 下载在后台执行，支持取消。验证引擎与运行库的固定 SHA256，再验证所选模型的拼接 SHA256；安装后探测引擎。
5. 已有模型或组件内容不匹配时拒绝覆盖。校验成功后自动合并并原子保存可信清单；清单仅为内部安全机制，不再提供手动导入界面。下载与推理互斥。

6. 一键下载按 Windows x64、Linux x64、macOS 平台选择固定资源；引擎位于 `models/upscayl-4f39acfc6f88/`，自动探测该位置。其他平台明确提示不支持。当前仅 Windows x64 完成真实 GPU 验收，禁止把下载支持等同于全平台验收通过。

7. 首页工具卡片最小高度 132 DIP，图标 44 DIP；窄窗口改为两列。侧栏不提供搜索框，不显示滚动条但保留滚轮滚动。当前工具所在分组允许折叠，页面不关闭；重新从首页打开工具时展开其分组。收起侧栏时隐藏全部分组标题及占位，并显示连续的工具图标，不让折叠偏好造成工具无法访问。

8. 设置页移除编解码能力、模型与组件目录介绍、减弱动效控件。AI 页显示所选模型适合的图像类型，保留校验状态与必要授权提示。
9. 固定哈希来自官方 HTTPS 下载实测，不等于上游签名、许可证分发批准或真实 GPU 推理验收。

### 9.9 发布前交互与模型目录契约

1. 所有页面只显示操作标签、参数、简短状态和必要安全警告。说明性段落与完整下载 URL 放在文档，不占据参数区域。
2. LOGO 圆环内部使用不透明白底，圆环外部保持透明；应用 SVG 与打包 PNG 同步生成并测试。
3. 默认模型目录为程序可执行文件同目录的 `models/`。默认值持久化为相对标记，移动便携程序后重新解析。升级后正常启动自动清退旧三个模型的已知文件、旧引擎和对应登记记录，移入各模型根目录的 `.trash/legacy-*`；同时检查旧配置目录的 `models/`。保留自定义模型与未知文件，不再向用户提供旧模型兼容。
4. 下载 ZIP 与解压暂存均位于模型目录。目录不可写时返回错误，不回退到用户数据目录或系统临时目录。
5. 推理输入先解码、应用 EXIF 方向并归一到 sRGB PNG；透明输入复合白底供引擎推理。PNG/WebP 输出按原图缩放恢复 Alpha，JPG 保持白底。Tile 只接受自动或不小于 32 的值。
6. 标注预览和导出共用 `engine.AnnotateImage`；后台渲染使用独立标注快照，不再用轮廓替代实际遮盖效果。

### 9.10 Upscayl 交互与临时缓存契约

1. AI 结果仅配对本次实际输入与实际输出。画布上方不放视图选项与缩放控件。左侧原图、右侧结果，左键拖动竖线实时对比；滚轮缩放，右键或中键拖动平移，双击复位。缩放和平移同步两侧源区域，不重新编码或重新推理。
2. 七个固定模型、1–16×、双重推理、自定义宽度、GPU 列表、Tile、TTA、PNG/JPEG/WebP 和压缩共用后端校验。批量队列串行进入 GPU；推理拒绝覆盖原图。自定义模型只导入文件对，不让用户选择模型存放位置。
3. 参数防抖保存，重置不删除模型。高级选项收纳自定义模型、跳过预览、完成通知、日志和本地统计。下载源与代理使用分段选择，不能把选中状态当作加载状态。
4. 粘贴原图写入 `models/.clipboard/session-*`；每个会话只清理自己创建的目录。实际退出时等待正在写入的原图完成或取消，再清理；关闭到托盘保留会话。正常启动清理超过 24 小时的遗留临时原图与下载暂存。
5. 设置页后台统计磁盘缓存，分类显示缩略图、临时原图、内置压缩工具、下载暂存和使用中容量。清理只操作白名单普通文件，拒绝符号链接目录，不递归删除未知目录。处理、导入、下载期间禁用清理；清理期间不启动新处理、粘贴或下载。
6. 当前会话临时原图不参与手动清理；模型、源文件、导出结果、旧模型回收目录不属于缓存。所有工具对临时原图的默认输出均指向程序旁的 `outputs/`。内置压缩工具清理后必须能重新释放并运行，不能缓存失效的可执行路径。
7. 所有工具共用列表、网格、紧凑三种输入排列；虚拟化只构建可见行。图片列表与预览统一保留左右 16 DIP 内边距，预览按剩余高度收缩并裁剪，图片保持原比例，不越过输入卡。
8. 预览按任务分配空间：PDF、GIF、图像分析不显示无意义的静态原图预览；格式转换、尺寸调整、压缩、图标、宫格、行列切分、长图拼接、取色使用小预览与大列表；编辑、拼图、对比与 AI 使用主画布。标注和拼图画布使用固定可用空间中的等比适配，不依赖图片固有高度撑开布局。

### 9.11 逐页体验审计契约

1. `docs/应用体验逐项审计与优化记录.md` 是体验问题的唯一台账，记录编号、页面、改动、证据与剩余限制。完成项只做回归，不重复改版。
2. 裁剪与水印的预览、导出共用纯图像渲染函数。裁剪预览限制长边 2048，导出保持用户指定尺寸。同源同工具更新效果时保留上一次完成的画面，显示更新状态；换图不得沿用旧来源画面。
3. 富文本默认值仅初始化一次。主题只在切换时应用，导出提交最终自定义颜色。无输入图片也能预览、导出；无输入时必须指定输出目录，禁止默认写入当前工作目录。
4. 文件队列支持三种排列内拖动重排。重排保留文件身份和处理结果；导入／处理期间禁止重排，队列变化导致旧顺序失效时拒绝提交。
5. Session 创建时固定设置文件位置。`settings.SaveTo(path, value)` 向指定路径原子保存；`settings.Save(value)` 保留按当前配置位置保存的接口。延迟后台写入不得改写其他会话的设置文件。
6. PNG 等不支持质量参数的目标不显示质量控件。多尺寸标签换行；密集预设使用共享索引的多列按钮，不拆成不能互相选择的局部分组。
7. 绘制只从图片实际区域内的左键按下开始，忽略留白和其他鼠标键。拖动坐标限制在图片范围；反向拖动不能被当成单击。PDF 密码使用掩码输入。
8. 分析按最后请求执行并拒绝过期结果；对比参数变化自动重新计算。计算中不导出旧指标。界面不显示内部对齐枚举，0 dB 必须显示为有效测量值。
9. 文件列表的 Delete 只移除选中队列项，不删除文件；导入或处理期间不执行。处理中禁用清空与输出位置选择，清空动作自身也必须检查运行状态。缩略图等比适配，不拉伸。
10. 空闲不显示无效取消按钮。存在成功队列输出时提供结果入口，优先定位选中项的实际输出，而不是按当前设置重新推算。重复选择已加载或加载中的图片不重复解码，失败项仍可重试。
11. 无输入的富文本和自由布局使用独立实时画布，不显示空队列，导出必须明确指定输出目录。独立结果仅在本会话内按工具保存；新任务开始清除对应旧入口；失败不沿用旧入口。独立导出不得将结果图写为其他工具的源图，自动打开使用实际结果目录。
12. 自由布局有输入时沿用共用批处理的计数、进度、跳过、取消和结果状态；无输入时记录独立结果。添加图片图层默认使用选中输入；退出预设称为“自定义”，不清空图层；列表中的形状名称使用中文。
13. 多尺寸、宫格、行列切分、GIF 帧导出必须通过共用目录预留执行跳过／重命名，不能绕过目录冲突策略。GIF 帧区间使用从零计数、左闭右开、结束 0 为末尾；无效区间不得创建输出目录。
14. 图像分析的统计和像素取样共用本次解码的源图，新请求立即使旧数据失效。对比重算立即使旧指标和差异图失效，交换来源后重新计算；缺少来源不能启动计算。
15. 对比报告成功保存后记录独立结果；查看入口不能被共用队列中的其他任务输出替代。分析无导出操作，不显示其他任务的结果入口。
