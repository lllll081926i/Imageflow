# Go 图片工具箱 · 页面与交互详细规格（UX 交付稿）

> **2026-11-17 仓库适配修订**：软件基线为 `v3.1.0`，不是本包版本号。先读 [M0 仓库对齐与增量实施基线](../04_实施与测试/M0_仓库对齐与增量实施基线.md)。本次只优化规划；源码核查、历史测试、人工验收和性能实测分别记录。

> 配套 PRD v2.0；属于**建议设计规格**，不是对现有应用源码/UI 实现状态的证明。以 PRD 第 4–10 章为范围基线。UI 框架、现有组件实现与组件库尚待 M0 盘点。凡涉及新功能页面的验收，均须与真实 Go Core 能力一致。

## 1. 信息架构与模块语义

- 首页：搜索工具、常用入口、最近使用工具；本地历史不应保存用户图片副本。
- 基础处理：格式转换、尺寸调整、图片裁剪、图片压缩、基础编辑。
- 创作与排版：宫格切图、图片布局、图片拼图、长图拼接、批量水印、富文本制图、图片标注、截图美化。
- 专业图像：专业调色、图片滤镜、图片对比、图像分析；位图转矢量作为后期高级项。
- 动态与素材：GIF/动图工具、图标生成、色彩提取、像素画/点阵图、表情包制作；视频帧提取及素材生成后置。
- 智能增强：AI 高清放大；智能抠图后置，图片修复/对象擦除仅预研。
- 设置：导出偏好、性能与缓存、格式能力、模型与组件、隐私、语言、许可证。
- 旧“转 PDF”：已知有入口，但功能冻结；不强制移除，后续位置以当前项目兼容性评估为准。

**不可新增** OCR、文档扫描、独立批量管理中心、开发者工具、图片云同步、全能图层编辑器。

## 2. 页面通用布局

### 2.1 桌面标准布局

1. 左侧导航栏：分组可折叠、常用收藏、工具搜索。所选分组高亮，当前工具高亮；侧栏不因加载大图失去响应。
2. 工作区顶部：返回、当前工具名、源图信息、撤销重做、帮助说明；如适用显示格式、像素、体积、帧数、透明与 ICC。
3. 中央预览区：拖入区域/图片画布，适应窗口与 100% 显示，滚轮缩放、抓手平移、透明棋盘底。
4. 右侧参数区：分组折叠，字段含标签/单位/默认值/合理范围/一键复位；禁用项显示原因而不是静默消失。
5. 底部输出栏：目标格式、保存位置与文件名、文件体积预测（确有可信估算时）、导出按钮和取消按钮。

窄窗口时右侧参数改抽屉，预览占优先空间；高 DPI 100%、125%、150%、200% 均检查视觉布局。主工具页不使用无意义的多级弹窗。

### 2.2 通用状态

| 状态 | 触发 | UI 反馈 | 允许操作 |
|---|---|---|---|
| EMPTY | 没有导入图片 | 拖放/文件选择、格式提示 | 导入/粘贴 |
| LOADING | 读取/解码中 | 可取消，若可得显示阶段 | 取消 |
| READY | 已读入且参数有效 | 预览、元信息、参数 | 编辑/导出 |
| PREVIEWING | 预览计算 | 旧预览可保留但标记更新中 | 修改参数/取消旧任务 |
| EXPORT_READY | 可导出 | 目标路径与格式有效 | 导出 |
| EXPORTING | 生成临时文件 | 任务阶段、进度或不确定指示 | 取消，禁止重复提交 |
| SUCCESS | 文件完成校验 | 路径、体积、尺寸、打开文件/目录 | 继续编辑/重新导出 |
| ERROR | 输入/编码/权限/GPU 失败 | 错误原因、错误码、恢复动作 | 重试/返回 |
| CANCELLED | 用户明确取消耗时任务 | 清理中的短时状态，恢复编辑 | 重试 |

AI 专属：COMPONENT_MISSING、MODEL_MISSING、GPU_UNAVAILABLE；不能把 GPU 缺失误写成“无网络”。

### 2.3 全局微交互

- 拖动滑块时采用防抖与递增任务序号；只允许最后一次参数快照成为有效预览，避免旧结果覆盖新结果。
- 数字输入与滑块双向绑定；滑块双击复位到参数默认值，明确步长与单位。
- 编辑前后对比支持左右分栏、分割线和按住键临时查看原图；不同尺寸应说明映射方式。
- 键盘：Ctrl+Z 撤销、Ctrl+Shift+Z 重做、Ctrl+O 打开、Ctrl+S 导出（若不冲突）、Ctrl+0 适应窗口、Ctrl+1 100%。在输入文本焦点时不要误触发全局动作。
- 保存时默认生成新文件，不覆盖原图。对同名目标采用“另存/覆盖并确认/取消”，不能靠自动静默覆盖。
- 明确告知动画转换为静态图片会丢帧；输出支持矩阵依据运行时能力注册表。

## 3. 各模块页面交互规格

### 3.1 BAS-01 格式转换

**页面**：输入信息卡；输出格式卡；动图策略卡（只有多帧时显示）；透明背景与元数据策略；预览与体积比较。

**规则**：只有确实存在编码实现的格式可选择。Alpha→JPEG 强制定义背景色；动图→不支持动画的格式，要求选择首帧/指定帧；动图保留需要可用的动画编码能力。失败时显示格式和失败阶段；逐张处理可以显示文件级结果，但不产生独立任务管理中心。

**边界用例**：错误扩展名、EXIF 旋转、含 P3 ICC、半透明 PNG、多帧输入；全部可预览真实结果。

### 3.2 BAS-02 尺寸调整

**参数**：模式（像素/%/最长边/最短边）；宽/高；锁定比例；Fit/Fill/Pad/Stretch；插值算法；禁止放大；填充背景；保存为当前工具预设。

**预览**：包含原图边界与目标画布示意，Fit/Pad 时画布与内容位置分开标注。修改 DPI 时显示“仅更改元信息，不改变像素尺寸”。

### 3.3 BAS-03 图片裁剪

**工具**：自由框、常用比率、自定义 X/Y/W/H、三分网格、居中、旋转、拉直、自动去边、形状蒙版。

**交互**：拖动四边/四角、移动选区；自动裁边只是生成建议框，可撤销；坐标以 EXIF 旋正后图像为标准。圆形裁剪与 JPEG 不透明输出需要明确底色。

### 3.4 BAS-04 图片压缩

**主控件**：模式切换“画质优先 / 体积优先 / 指定大小 / 无损优化”；目标格式；分辨率政策；元数据政策；算法高级区（按编码器能力动态显示）。

**效果区域**：原/结果滑动比较；实际输入大小、结果大小、节省比例、耗时、目标体积是否达成。预估值要标注“预估”，不能当最终结果。

**异常**：目标体积无法实现→展示最接近结果并说明差距；输出更大→提醒；编码器不提供质量参数→隐藏虚假滑块；取消后回到可编辑态。

### 3.5 BAS-05 基础编辑

仅包括旋转/翻转/画布扩展/边框/圆角/阴影/透明背景/基础锐化模糊。**不**把曲线、高级 HSL、图层标注塞进这个页面；引导至专业调色或图片标注。

### 3.6 CRE-01 宫格切图

提供行列预设、任意行列、编号方向、边界预览、留白间距与分割区域区别提示。导出可选单块或全部 ZIP；1001×667→3×3 不许漏像素。

### 3.7 CRE-02 图片布局

画布与图层面板：背景/图片/文字/形状图层；支持锁定、隐藏、选择、拖动、对齐、等距分布、层级调整、蒙版。项目保存（可编辑 JSON）作为 P2，不与 PSD 兼容。关键交互是对象选择与属性映射，而不是自动拼图。

### 3.8 CRE-03 图片拼图

1–16 张图导入（保留现有数量范围）→模板选择→拖动排序→单格缩放/平移→整体间距/留白/圆角→导出。用户不需要理解复杂图层。不同图片方向使用 Fit/Fill 显式策略；模板切换不丢输入顺序。

### 3.9 CRE-04 长图拼接

排序列表、方向、宽度/高度统一策略、接缝预览、自动重叠置信度、手动偏移。低置信度不自动裁掉图片内容；超长输出可分段导出。对固定导航栏/重复按钮允许指定排除区域。

### 3.10 CRE-05 批量水印

文字/Logo/平铺；位置九宫格；透明度、角度、尺寸；支持 `{filename}`、`{date}`、`{index}` 变量预览；本工具可导入多张，逐张显示结果，不增加跨工具批量中心。

### 3.11 CRE-06 富文本制图

编辑区、样式面板与图片预览。标题、段落、引用、列表、代码、字体、行高、背景、内边距、图片嵌入；可使用有限 Markdown 语法组织图片元素。该入口**不支持** OCR、Word/PDF 导入、文档扫描或可搜索 PDF。

### 3.12 CRE-07 图片标注

工具栏：箭头、线、矩形、椭圆、笔、文字、编号、局部高亮、马赛克、模糊、**不透明安全遮盖**。安全遮盖需说明不同于模糊；导出时只保留最终合成像素，不能在导出文件中残留隐藏底图。

### 3.13 CRE-08 截图美化

导入截图；选择纯色/渐变/图片背景；设置留白、圆角、阴影、背景比例与轻量设备边框模板。系统实时截图捕获仅 P2，需验证 UI 框架与操作系统 API 后开放。

### 3.14 PRO-01 专业调色

可折叠组：曝光与对比、明暗、白平衡、色阶、曲线、HSL、LUT。每组提供参数重置；曲线可添加/删除控制点；LUT 导入显示尺寸与兼容错误。始终提供直方图与原/结果同步对比。显示当前色彩管理模式及可能的精度降级。

### 3.15 PRO-02 滤镜

滤镜库以缩略图展示，支持强度调节、应用顺序和滤镜组合；零强度需保持原图（定义浮点与输出编码容差）；不要把一般滤镜宣传成 AI 修复。

### 3.16 PRO-03 图片对比

左右并排/拖动分割线/透明叠加；同步缩放与坐标；P1 包含差异图、PSNR、SSIM。图像尺寸或色彩空间不同而缺少有效映射时，指标区域显示“不可计算”及原因。

### 3.17 PRO-04 图像分析

信息卡与 R/G/B/亮度/Alpha 直方图；过曝/欠曝热区、半透明比例、像素取样。大图采样统计需明确“采样”标记，不冒充全量精确统计。

### 3.18 PRO-05 位图矢量化（P2）

黑白轮廓描摹：二值阈值、平滑、节点简化、路径预览与 SVG 导出；彩色描摹只有独立适配器验证后开放。SVG 必须是路径，不是嵌入位图容器。

### 3.19 MED-01 GIF/动画编辑

播放器、时间轴、帧缩略图、时长、循环次数、帧复制/删除/倒序/逐帧文字、动画裁剪与缩放。内核须先正确还原完整可显示帧与 disposal；后处理后重建目标动图。动态 WebP/APNG 则分别标记解码、编码支持，不能只显示“支持”。

### 3.20 MED-02 图标生成

图标尺寸复选、适配模式、透明边缘与安全区域、不同尺寸预览。可导出单一多层 ICO、各尺寸 PNG 或 ZIP；“图标生成”只服务图片/图标用途，不升级成开发者资源工具。

### 3.21 MED-03 色彩提取

放大镜取色；颜色模式显示 HEX/RGB/HSL/HSV/A；主色占比及调色板复制；可选择合成背景处理半透明像素。WCAG 对比度建议是参考值，不表示作品获得无障碍认证。

### 3.22 MED-04 视频帧提取（P2 可选）

视频选择→时间点/时间间隔/帧率→选帧预览→图片/故事板导出。没有 FFmpeg 组件时显示明确说明，不影响其他图片页。限制在“视频转图片”，不做视频剪辑和录屏。

### 3.23 MED-05 像素画与点阵图

目标尺寸、颜色数与调色板、None/Bayer/Floyd–Steinberg/Atkinson 抖动、最近邻缩放、像素网格、黑白反相。严格黑白模式明确输出 PNG，禁止 JPEG 无意产生灰度中间值；提供 400×300 预设。

### 3.24 MED-06 表情包

图片或动图导入、字幕位置/描边/字体/气泡样式、静态与动态时间范围、播放预览与体积限制。所有帧时间语义来自 MED-01，不另写动画处理内核。

### 3.25 MED-07 素材背景生成（P2）

渐变、棋盘、条纹、网格、圆点、简易纹理、背景透明、随机种子。相同配置和种子输出可复现，不能以“素材生成”自行引入云端 AI 生图。

### 3.26 AI-01 本地高清放大

环境探测卡（引擎、GPU、驱动、模型）、图片导入、模型类别、倍率/输出尺寸、局部预览、Tile/TTA 高级区、运行与取消、输出对比、模型安装/移除。引擎/模型/GPU 缺失分别给不同状态。AI 的完整功能不进入普通工具的启动热路径。

## 4. 跨页面设计组件清单

| 组件 | 主要责任 | 复用范围 |
|---|---|---|
| AssetInfo | 真实图片参数与能力 | 所有图片页 |
| DropZone | 文件选择/拖入/粘贴 | 所有需导入的页 |
| ImageViewport | 缩放/平移/棋盘格/像素定位 | 基础、专业、创作 |
| BeforeAfter | 对比与同步视图 | 压缩、调色、滤镜、AI、独立对比 |
| ParamControl | 统一数值/滑块/单位/范围 | 所有可调节算法 |
| CanvasObjectPanel | 图层和对象属性 | 布局、标注、水印、截图美化 |
| FrameTimeline | 帧/时长/循环语义 | GIF、动态表情 |
| ExportPanel | 格式能力/路径/元数据/冲突 | 所有输出页 |
| ErrorRecovery | 错误码/原因/恢复建议 | 所有页面 |
| ComponentStatus | 引擎、模型、许可与安装 | AI、可选视频/格式组件 |

## 5. 设计交付验收清单

- [ ] 每个 P0、P1 入口至少设计空态、加载态、正常态、导出态、成功态和异常态。
- [ ] 预览与导出显示的是同一个操作链，只有分辨率/缓存策略不同。
- [ ] 所有破坏性输出、覆盖原图、删除模型组件都有确认或明确可恢复规则。
- [ ] 没有可用引擎的格式/AI 能力不可显示为“已经支持”。
- [ ] 全部页面在 Windows 100–200% DPI 下无主要控件溢出，中文文件名可显示。
- [ ] 从任一工具导出完成后可打开文件或目录，不会让用户寻找结果。
- [ ] 不因新增模块修改已有 14 个入口的基础可用性；旧转 PDF 冻结维护。

## 仓库适配约束（2026-11-17）

- 保留 MyGo + Lobe MyGo 及现有控件行为，不以新导航分组强制重做 GUI。
- 先迁移旧侧栏索引到稳定工具 ID，再新增分组或工具；保留用户顺序与拼图参数。
- 拼图兼容 1–16 张。现有 LayoutTool 不是自由图层布局；新画布是增量需求。
- 严格黑白和真正 PNG 1-bit 编码是两个不同选项/能力。未实现位深写出时，不显示“1-bit PNG 已支持”。
- 新页面未通过真实导入、处理、导出与重开验收前，不以演示状态对外开放。
