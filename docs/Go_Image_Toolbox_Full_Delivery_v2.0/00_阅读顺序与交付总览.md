## 1. 产品边界（本包唯一有效范围）

包含：
- **基础处理**：格式转换、尺寸调整、裁剪、压缩、基础编辑。
- **创作与排版**：宫格、布局、拼图、长图、水印、富文本制图、标注、截图美化。
- **专业图像**：调色、滤镜、对比、图像分析、进阶矢量化预研。
- **动态与素材**：GIF/动图、图标、取色、点阵/像素图、表情包，可选视频抽帧与素材背景。
- **智能增强**：基于 Go 调度和可选 NCNN/Vulkan 原生引擎的 AI 高清放大，功能体验参考 Upscayl。

不包含：OCR、文档扫描和文档功能扩展、新增开发者工具或 CLI/API、独立批量管理中心、图片去重/相册管理中心、必须联网的图片服务。

已有“转 PDF”入口**冻结兼容**。保留现有 `cmd/imageflow-batch`、`cmd/imageflow-icon` 的 CLI 行为。保留六平台构建与签名更新链。新增功能不得降低现有拼图的 1–16 张上限。

## 3. 文档之间出现分歧怎么办？

优先级顺序：**用户最新明确指示 > 仓库适配后的 PRD v2.0 产品需求（含 M0 兼容约束）> 审查记录中的统一解释 > 专项 UX/技术/测试方案 > 开发规范 v1.0**。若冲突影响源文件安全、许可证或兼容性，先暂停该项功能的发布并创建 ADR，不得由 Agent 直接猜测。

以下属于重要解释：
- “Go 原生优先”重点是处理核心与任务逻辑，不表示 AI GPU 推理必须纯 Go，亦不意味着没有源码调查就推翻前端。
- “不做独立批量管理”允许工具内部批量水印、批量导出宫格或 GIF 帧等。
- “不做文档功能”与现有“富文本制图”并不冲突：它输出图片，而非文档解析；旧“转 PDF”只是冻结兼容。
- 像素画/点阵严格黑白输出是实际像素验收，不能使用有损 JPEG 输出后声称只有黑白两色。
- Upscayl 类体验不等于复制 Upscayl 代码/模型；引擎许可证和模型权重分别审查。
