## 2. 14 个入口与真实差异

入口位于 `internal/ui/app.go`：Convert、Resize、Crop、Grid、Layout、Collage、Stitch、Watermark、Palette、Icon、PDF、GIF、RichText、Compress。

详细需求状态以 [需求追踪矩阵](../01_产品需求/需求追踪矩阵.md) 为单一来源。重点差异：

1. LayoutTool 当前是裁正方形后按行列切图，不是自由图层布局。CRE-02 需要共享画布增量。
2. 拼图已有 1–16 张、取景、标注、背景、参数持久化与异步预览。保留这些能力；新模板、拖动换序逐项开发与验收。
3. 长图已有顺序拼接，不包含自动接缝匹配。
4. 动图已有 GIF/APNG/动态 WebP 内核；完整 GUI 时间轴仍需开发。
5. ICC 与 HDR 处理已有实现及回归，不等于专业调色、任意高位深或完整色彩工作流。
6. 独立基础编辑、专业调色、滤镜、对比/分析、像素画、表情包、AI 页面尚未实现。拼图局部标注不等于通用标注工具。

## 3. 保留与扩展决策

下列决策适用于本次计划，不表示已经修改对应代码。

| 组件 | 已有实现 | 实施决策 |
|---|---|---|
| GUI | MyGo + Lobe MyGo | 保留；不引入 Wails/Fyne 替换工程 |
| 编解码 | `internal/codec`、jpegli/libwebp/libavif/OxiPNG、APNG | 保留；扩展真实多维能力表，不为候选库简介换依赖 |
| 色彩管理 | `internal/colorprofile/wasm.go` 与嵌入 LCMS/WASM | 保留；不是纯 Go 重写 LCMS；高精度另验证 |
| 动画 | `internal/engine/gif.go` | 复用合成帧、时长和资源预算，再做时间轴 |
| 裁剪/多尺寸 | `cropbox.go`、`preset.go` | 复用既有模型，不新建重复几何内核 |
| 结果协议 | `internal/engine/result.go` | 保留 Success/ErrorCode/Skipped，使用适配扩展逻辑契约 |
| 导出 | `internal/output/output.go` | 复用 CheckSize/CheckImage/Atomic/Commit；文件系统错误另补证 |
| 会话 | `internal/batch/session.go` | 保留输入身份/runID；另增操作历史，不把批任务会话当 Undo/Redo |
| AI | 尚无产品实现 | 可选独立组件；默认安装和离线核心不依赖模型 |

### 3.1 MyGo 生命周期与异步约束

- 后台执行解码、合成、编码和分析。通过 `Window.Update` 发布结果。
- 保存数据、控件状态和稳定身份，不保存跨帧 Element 或工作线程中的 `ui.Context`。
- 切换输入、连续调参和关闭窗口时取消旧请求或拒绝过期结果。
- 删除输入行、清空列表、运行新批次后，旧结果不得回填到其他输入。
- UI 改动复用 `ui.NewTester`，覆盖额外帧、控件消失/重现、焦点与取消。

### 3.2 配置、CLI 与发布兼容

- 保留 `cmd/imageflow-batch` 和 `cmd/imageflow-icon` 的既有参数、输出路径、冲突策略及退出结果。不新增 CLI/API。
- 保留历史 PDF 功能，冻结扩展。
- `internal/settings/settings.go` 的 `RailOrder []int` 使用 Tools 索引。新增工具或分组前，先定义稳定工具 ID 与旧索引映射。
- 迁移测试覆盖旧索引顺序、缺失/重复/越界值、默认新增工具和再次保存/加载。迁移不能改变已有工具身份，也不能覆盖用户拼图参数。
- 保留重命名/覆盖/跳过策略。文件失败、跳过与成功分别返回，不丢弃批次已成功结果。
- 保留六平台构建和签名更新验证。对新 AI 平台单独设兼容矩阵；不支持 AI 时核心仍可用。

## 4. 分批实施顺序与准出

不按文档页数估工期，不把所有 P1 合并为一个小版本。每批独立编译、回归和评审。

| 批次 | 任务与依赖 | 交付物 | 准出条件 |
|---|---|---|---|
| A：兼容基线 | M0-01/02/04/08；现有回归 | 子需求差异、配置迁移方案、CLI/六平台回归清单 | 源码与需求可追踪；未覆盖项明确登记；原功能不被删减 |
| B：共享 P0 | CORE-01…04、CORE-09/11；依赖 A | 能力注册适配、共享对比、编辑历史最小闭环、安全导出补证 | 输入→修改→撤销/重做→预览→导出→重开；过期结果与原图保护通过 |
| C：基础编辑 | EDIT-01…03；依赖会话与几何内核 | BAS-05 分批交付，不重做专业调色 | 对应 PRD 子项、Alpha、预览/导出一致性及回归通过 |
| D：创作增量 | CREATE-01…08；共享画布先行 | 布局/标注/文字；拼图与水印增量 | 1–16 张不退化，CJK/坐标/模板和旧设置用例通过 |
| E：动态素材 | MEDIA-01…07 依赖 B；MEDIA-08 另依赖 CREATE-01 与动画任务 | 动画边界/时间轴、图标、点阵、表情 | 帧时序、黑白像素、PNG 位深、ICO 实机分别验收 |
| F：专业图像 | STUDIO-01…05；依赖共享会话/对比及色彩策略 | 调色、滤镜、分析与指标 | 工作空间明确；不以 8-bit 链宣称任意高精度 |
| 独立 AI | AI-01…06；依赖 M0 许可/设备、M1 任务/导出和共享对比 | 引擎 PoC、模型注册与 GPU 证据 | 获批模型、哈希、取消无残留、质量对照及组件分发通过 |
| 后续高级项 | M6；按单项选择依赖 | P2/P3 独立提案 | 不计入当前小版本承诺 |

M0-03 性能与 M0-06 许可补证按受影响模块执行。没有性能前后对照不得宣称优化提速；没有获批权重不得开放 AI 发布。资料包候选接口通过适配接入，不要求先迁移全工程目录。
