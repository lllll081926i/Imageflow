## 1. 测试层级与发布门槛

| 测试层 | 必需内容 | 发布规则 |

## 3. 18 个必需 E2E（PRD 原编号 + 可执行步骤）

### E2E-01 透明 PNG → JPEG

- 准备含半透明抗锯齿边缘的 PNG；选择转换为 JPEG，并指定纯蓝或纯白背景。
- 导出后重新解码；检查无透明通道，背景色与预期一致，不出现错误黑色光晕。
- 取消/导出错误时源图 SHA256 不变。

### E2E-02 EXIF 旋转 JPEG → PNG

- 准备 Orientation 6 和 8 的 JPEG，导入后呈现正常视觉方向。
- 导出 PNG，尺寸应按实际旋正后方向变化，重新导入不再次旋转。
- 不支持读取 EXIF 的环境不得静默宣称自动方向正常。

### E2E-03 目标 200 KB 压缩

- 用照片/截图分别设置目标 200 KB；记录迭代次数、输出体积、像素尺寸。
- 达标时真实文件体积应在产品定义误差范围内；不可达时明确显示“未达成”及最接近方案。
- 不得自动降低像素分辨率，除非用户启用该策略。

### E2E-04 1001×667 九宫切图

- 导入奇数尺寸样本，3×3，无视觉间隙；逐块重新拼接到原坐标。
- 所有像素恰好覆盖原图一次；无重复、空洞、误裁边。

### E2E-05 多图拼图换序

- 分别用 1、6、9、10、16 张具有唯一标识的测试图，载入、模板切换、拖动排序后导出。
- 导出的每格图片顺序与 UI 一致；切换模板不丢图、不复用旧缓存图。

### E2E-06 长截图重复匹配不确定

- 构造含相似段落、固定顶部导航和重复按钮的长截图组合。
- 自动匹配低置信度时须弹出手动接缝选项；未经确认不得删除内容。

### E2E-07 安全遮挡敏感信息

- 在合成的银行卡号样例区域使用“不透明安全遮盖”。
- 导出后重新读像素并确认遮盖区不包含底层细节；不可编辑图层导出中不能藏着原文本像素。
- 普通模糊或马赛克不得被 UI 标示为“安全不可逆”。

### E2E-08 P3 ICC 图片调色

- 使用授权的 P3 与 sRGB 对照样本和真实 ICC Profile。
- 对比输入识别与输出可见色彩，验证转换政策；如果工作空间受限需明确展示告警。

### E2E-09 异尺寸图片对比

- 加载 1000×1000 和 1600×800 图片；未提供几何/颜色空间映射时 PSNR/SSIM 必须不可用。
- 选择明确对齐后再计算；差异图需显示采用的变换策略。

### E2E-10 复杂 GIF 变速

- 准备 disposal 2/3、局部帧、不同帧时长、透明叠加的授权固定文件。
- 先验证播放复合帧，再调整帧时长、重排、保存、重开逐帧核对画面与总时长。
- 对 0 或异常帧时长按明示策略处理，不隐式修复为完全不同速度。

### E2E-11 400×300 严格黑白

- 导入包含渐变/文字/细线的图片，设 400×300、1-bit 黑白、Atkinson/Bayer 等模式。
- 导出 PNG 重新解码；宽高精确；像素色集合只能是黑/白（或退化到其中一种），不存在灰色与 JPEG 噪声。

### E2E-12 动态表情按帧区间加字

- 给 12 帧 GIF 的第 4–8 帧添加大字标题。
- 导出并重开；指定区间正确，其他帧不出现文字，帧时长、透明合成与循环符合预期。

### E2E-13 无 AI 组件启动

- 安装最小 Core 包，不添加 NCNN、模型、FFmpeg；启动并完成转换/缩放/压缩/静态 PNG 导出。
- AI 页面显示缺失提示，但普通页面无错误、无相关后台进程。

### E2E-14 AI 显存不足并取消

- 在允许的 GPU 环境中选择过大任务或可模拟的推理 OOM；UI 显示合理修复动作。
- 取消后检查所有相关进程关闭、临时结果清理、核心页恢复可用。

### E2E-15 导出时磁盘满

- 将输出目录置于受控容量环境，使写入中途失败。
- UI 不显示成功，目标目录无伪完整输出，源文件 SHA256 不变。

### E2E-16 中文及特殊路径

- 使用包含中文、空格、emoji 的路径及文件名，在所有 P0 核心工具完整处理。
- 文件读取/保存/打开目录成功；用于外部组件的参数必须独立传参，不通过 shell 字符串转义。

### E2E-17 不可读 GIF 帧

- 导入截断/坏局部帧 GIF；应给出 CORRUPT_IMAGE 或受检验的等价错误码。
- 不会无限 CPU 占用、泄漏内存或进入无限重试循环。

### E2E-18 版本升级兼容

- 保存前一版本用户预设、常用入口、导出偏好，安装更新。
- 原有设置在版本迁移后仍可使用；失败有迁移回滚策略，不会删除原本用户文件。

## 4. 算法专门回归

| 算法族 | 数值/结构断言 | 重点边界 |
|---|---|---|
| Resize | Fit/Fill/Pad 尺寸与像素映射 | 1×1、极端比例、透明边 |
| Crop | 结果 X/Y/W/H 与 preview 一致 | EXIF、圆形蒙版、出界 |
| Canvas | 图层 z-order、透明混合与文字坐标 | 圆角/阴影/CJK |
| Long stitch | 置信度、重叠裁切与内容保护 | 相似区域误匹配 |
| Filter | 0% 与原图一致、100% 对应实际算法 | Alpha、Gamma、顺序 |
| LUT | .cube 规格解析、越界拒绝 | 异常维度、浮点 NaN |
| Histogram | 黑/白/纯色结果分布 | 透明像素与采样模式 |
| Color picker | 源像素与显示色空间转换可解释 | ICC/Alpha |
| SVG | 真 SVG 路径，闭合/洞和节点数 | 退化二值图 |
| GIF | 帧数、合成可见帧、帧 duration | disposal、loop、offset |
| ICO | 多尺寸、透明图层可识别 | Windows Explorer |
| Dither | 严格两色/可复现 | 误差扩散边界、奇偶行 |
| AI | 尺寸、任务成功、取消、模型 hash | Vulkan/OOM/不兼容权重 |

## 5. 性能验证方法

### 5.1 测试环境

- 设备 A：Win11 x64、8 GB RAM、普通 SSD/核显或较低性能设备。
- 设备 B：Win11 x64、16 GB RAM、适当独立 GPU。
- 固定电源计划、操作系统构建、显卡驱动、项目 commit、Go 版本与输入 SHA256。
- 冷启动每次完全退出所有子进程，热启动单独统计；测试至少重复 20 次（首屏建议 30 次），报告 P50/P95，而非单次最快耗时。

### 5.2 建议验收目标（M0 建立基线后可调）

| 指标 | 建议目标 | 实际值 |
|---|---|---|
| Win11 冷启动至可交互 | P50 ≤2s | 待测 |
| 空闲全进程私有工作集 | 争取 P50 ≤150MB | 待测 |
| 2000×1500 JPEG 首屏预览 | P95 ≤600ms | 待测 |
| 低清参数滑动反馈 | P95 ≤250ms | 待测 |
| P0 端到端用户任务成功率 | ≥95% | 待测 |
| 无授权源图修改 | 0 次 | 待测 |
| 严格 1-bit PNG | IHDR bitDepth=1；colorType=0 或 3；有效调色板仅黑白；解码全黑白且无半透明 | 待测 |
| AI 性能 | 同配置与官方宿主 A/B，报告原始数据 | 待测 |

**统计口径**：包含 UI 及所有子进程；结果必须写明是否含模型加载、是否含输入预处理、是否含输出编码。不能只测纯算法耗时来代表用户体验。

## 6. 安全与故障注入

- 输入魔数与后缀不一致，截断流，不合法像素尺寸/帧数，解压后内存超限。
- 写入只读目录、满磁盘、路径冲突、文件句柄被其他进程占用、Windows 长路径。
- 预览频繁修改参数并连续取消；应用在导出时退出；临时文件存在于同卷/不同卷的行为。
- 模型哈希被篡改、模型缺失、NCNN 进程返回非 0、stderr 报错但 exit 0、输出未生成或输出为 0 字节。
- GPU 运行中断、驱动兼容性、Tile 过大、取消后孙进程残留。
- 攻击面检查：外部 exe 必须以可信绝对路径调用、用户文件名不能变成命令参数、SVG/ICC/ICO/GIF 解析器必须有限额。

## 7. 缺陷严重程度

| 等级 | 示例 | 发布处理 |
|---|---|---|
| Blocker | 无授权覆盖源图、可利用的命令注入、重大数据泄露、导出伪成功 | 不发布 |
| Critical | 高概率 GIF 错帧/偏色、模型不合规、正常文件导致永久 UI 卡死 | 不发布相关模块 |
| Major | 某种支持格式无法写出、部分主流程不能正确取消、截图文本溢出 | 相关模块不能宣称正式可用 |
| Minor | 非阻断性文案/视觉瑕疵 | 修复排期和已知问题声明 |

## 9. 准出结论与未齐备材料

- 可以用本交付包中的合成样本立即执行基础 PNG/JPEG、宫格、透明、黑白与简单 GIF 测试。
- ICC/P3/16-bit、复杂 disposal GIF、APNG/动画 WebP、不同驱动 GPU、外部视频、真实照片仍缺样本；必须在对应模块发布前补充。
- 已取得仓库与历史测试/构建证据，见 M0 基线。新增 E2E 仍为未执行；没有设备或模型的项目登记具体原因。历史单测不能替代人工 E2E、性能或 GPU 验收。
