# 发布前验收（2026-11-17）

## 验收范围

验收当前工作区的 25 个工具、共享导航和设置、文件安全、可选 AI 组件、原生 Windows 启动及打包。不把路线图延期功能伪装为已交付能力。用户后续授权：验收通过后提交、推送并发布 `3.2.0`，通过云端构建生成发行文件。

## 实施与门禁

1. 核验工具切换、搜索、分组、窄窗口、主题、滚动和键盘操作。
2. 用真实输入操作参数、预设、撤销重做、图层、标注、预览和导出。
3. 检查设置输入、保存重启、模型选择、代理和组件状态同步。
4. 执行真实 GPU 大图、奇数尺寸、透明输入、取消、坏输入和输出保护验收。
5. 执行测试、竞态、静态检查、依赖漏洞扫描和六平台编译；构建 Windows 验收包。
6. 保存截图、日志和问题回归，区分通过项、延期项和发布阻断项。

## 本轮修复

- LOGO 内部白底不透明，外角透明；SVG 与打包 PNG 一致。
- 全部界面移除重复说明，保留操作、状态、许可证与安全提示；修复窄窗口输入标题挤压。
- 修复色值输入跨帧丢失、独立工具开始按钮禁用、启动工具参数和截图等待；标注预览显示真实遮盖结果。

- 修复真实 GPU 透明输入变全透明；规范格式、EXIF、色彩输入并恢复 PNG/WebP Alpha；拒绝过小 Tile。
- 限制 LUT 超量数据、重复尺寸与 float32 溢出；升级 Go 1.27.4 和相关依赖，撤回无依据的模型非商业许可断言。

## 云端强制门禁

`.github/scripts/verify-windows.ps1` 只允许在 GitHub Actions 临时目录运行。检查全新安装、3.1.0 原路径升级、模型目录保留、原生导入启动、卸载和便携移动后启动；不会覆盖本机已有安装或注册表。证据保存为 `windows-acceptance` artifact。

分支手动运行只构建验收，不发布。标签运行校验版本、生成签名更新清单及 SHA256SUMS，并在全部构建成功后发布。

## 验收边界

- Linux、macOS、Windows ARM64 未执行人工原生运行；六平台编译成功不等于这些平台人工验收。
- 未执行显存极限、长时间稳定性、P50/P95 或全场景画质评测；AI 不承诺恢复真实细节，透明边缘不承诺严格色度一致。
- 已覆盖输出写失败，但未物理填满磁盘；延期的时间轴、接缝识别等不列为本版已实现。
- 安装包不含 AI 引擎及权重。固定哈希不替代授权审核；本报告不构成完整第三方分发法律意见。
