# 逐页交互与输出审计

范围：25 个原生工具页、首页和全局设置。主操作放在固定操作栏，不随参数区滚动。工具页空状态给出当前任务的下一步；导入时显示「取消导入」，批处理时显示「停止处理」。

| --- | --- |
| 格式转换 | 转换格式；先加图，再选输出格式 |
| 尺寸调整 | 调整尺寸；多尺寸模式改为导出多尺寸图片 |
| 图片裁剪 | 裁剪图片；在预览中调整范围 |
| 宫格切图 | 导出切片；先选宫格数量 |
| 图片布局 | 导出分割图；设置行列和填充方式 |
| 图片拼图 | 导出拼图；先加多图，再选排版 |
| 长图拼接 | 拼接图片；按列表顺序处理 |
| 批量水印 | 添加水印；设置文字和位置 |
| 色彩提取 | 导出色板；设置颜色数 |
| 图标生成 | 生成图标；选标志图片和输出格式 |
| 转 PDF | 生成 PDF；按列表设置页序 |

首页和关于页复用同一品牌位图。Windows 原生窗口、托盘和安装构建统一使用当前紫蓝渐变标志的衍生资源，不修改源图。

桌面按列表顺序规划目标，再启动并行任务。自动重命名按列表顺序分配后缀。跳过保留最先规划的目标。「直接覆盖」只覆盖批次开始前就存在的目标；若本批次已有行预留该路径，为后续行分配后缀。CLI 检查编码器实际使用的扩展名；全列表输出和多文件目录也参与冲突检查。

桌面验证矩阵：960×620 和 1440×900，浅色和深色。逐页检查固定操作栏，另有原有的首页搜索导航、设置、参数和代表性工具交互回归。矩阵不替代真实 GPU、原生文件选择器及跨平台安装验收。

## AI 放大专项

- 主操作按检测、下载、导入、就绪状态切换。输入为空时，就绪页面可直接选择图片。下载或导入取消后，等待后台退出再允许重试或推理。
- 普通操作保留模型、尺寸和输出。Tile、TTA 和 GPU ID 放入高级选项。尺寸区域显示选中图的预计输出；按宽度与按倍率不同时争夺最终输出尺寸。
- 批量推理按列表顺序串行执行。固定操作区显示正在处理的文件和单图进度。对比区标记原图与结果图；切图时恢复默认视图，并可在预览区恢复已关闭的预览。
- 交互测试使用离屏渲染和受控任务，不代替真实 GPU 推理或实际下载链路验收。

## 非 AI 页面复查

- 共用输入列表保留选中原图，只显示归属当前工具的最近一批结果。长图拼接导出后不再把输出图写入共用原图预览。
- 批量工具、长图拼接、PDF 和拼图按实际产出定位目录。批量结果分布在多个目录时，自动打开列表中第一个成功结果所在的目录。
- 自由布局和富文本制图的独立导出与批量导出均传递取消信号。已开始的绘制或编码可能需要等待当前步骤结束；提交前收到取消则保留已有文件。

## 工作时性能复查

- 列表、网格和紧凑模式复用最近显示的缩略图位图，最多保留 64 项。三种模式共用移除按钮，导入或处理期间禁用移除。
- 桌面批量规划以路径集合检查本批次预留项，保持原有冲突策略和文件顺序。结果回写按行标识查找，同时验证任务代次，阻止旧任务改写新结果。
- 批量取消沿用进度节流，不为每条未启动任务单独刷新界面。批次结束时仍发布完整计数。
- 缩略图解码和路径规划分别用微基准验证。微基准不代表完整导出的耗时，也不代表原生窗口帧率。
